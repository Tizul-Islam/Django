# Python: Input ও Output ⌨️🖨️

প্রোগ্রামকে ব্যবহারকারীর সাথে যোগাযোগ করতে হয়। **Input** দিয়ে ব্যবহারকারীর কাছ থেকে ডেটা নেওয়া হয়, আর **Output** দিয়ে ব্যবহারকারীকে ডেটা দেখানো হয়।

## ১. Output — `print()` ফাংশন

Python-এ কনসোলে কিছু প্রিন্ট করতে `print()` ফাংশন ব্যবহার করা হয়।

### মূল ব্যবহার:

```python
print("হ্যালো, পাইথন!")
# আউটপুট: হ্যালো, পাইথন!
```

### একাধিক মান প্রিন্ট করা:

```python
name = "রহিম"
age = 25

print("নাম:", name, "বয়স:", age)
# আউটপুট: নাম: রহিম বয়স: 25
```

`print()` ফাংশনে কোমা (`,`) দিয়ে একাধিক মান পাঠালে সেগুলোর মধ্যে স্বয়ংক্রিয়ভাবে space যোগ হয়।

### `sep` প্যারামিটার — সেপারেটর পরিবর্তন:

```python
print("রহিম", "করিম", "সালাম", sep=", ")
# আউটপুট: রহিম, করিম, সালাম

print("০১", "০১", "২০২৫", sep="-")
# আউটপুট: ০১-০১-২০২৫
```

### `end` প্যারামিটার — শেষের ক্যারেক্টার পরিবর্তন:

ডিফল্টভাবে প্রতিটা `print()` এর পরে নতুন লাইন (`\n`) আসে। `end` দিয়ে পরিবর্তন করা যায়:

```python
print("আমি", end=" ")
print("পাইথন", end=" ")
print("শিখছি")
# আউটপুট: আমি পাইথন শিখছি

print("লোডিং", end="...")
print("সম্পন্ন")
# আউটপুট: লোডিং...সম্পন্ন
```

## ২. String Formatting (স্ট্রিং সাজানো)

### Method 1: f-string (সর্বোত্তম ও সহজ)

Python 3.6+ এ f-string ব্যবহার করা যায়। এটাই সবচেয়ে সহজ ও readable:

```python
name = "রহিম"
age = 25

print(f"নাম: {name}, বয়স: {age}")
# আউটপুট: নাম: রহিম, বয়স: 25

# ভেরিয়েবলের সাথে গণনা
print(f"পরের বছর {name} {age + 1} বছরের হবেন")
# আউটপুট: পরের বছর রহিম 26 বছরের হবেন
```

### f-string-এ ফরম্যাটিং:

```python
price = 99.999
print(f"মূল্য: {price:.2f}")   # দুই দশমিক পর্যন্ত
# আউটপুট: মূল্য: 100.00

num = 42
print(f"সংখ্যা: {num:05d}")   # ৫ ডিজিট, শূন্য দিয়ে পূরণ
# আউটপুট: সংখ্যা: 00042

pct = 0.85
print(f"শতাংশ: {pct:.1%}")    # শতাংশ আকারে
# আউটপুট: শতাংশ: 85.0%
```

### Method 2: `.format()` মেথড

```python
name = "রহিম"
age = 25

print("নাম: {}, বয়স: {}".format(name, age))
# আউটপুট: নাম: রহিম, বয়স: 25

# পজিশন দিয়ে
print("{1} এর বয়স {0}".format(25, "রহিম"))
# আউটপুট: রহিম এর বয়স 25

# নাম দিয়ে
print("নাম: {n}, বয়স: {a}".format(n="রহিম", a=25))
# আউটপুট: নাম: রহিম, বয়স: 25
```

### Method 3: `%` ফরম্যাটিং (পুরানো পদ্ধতি)

```python
name = "রহিম"
age = 25

print("নাম: %s, বয়স: %d" % (name, age))
# আউটপুট: নাম: রহিম, বয়স: 25

# %s = string, %d = integer, %f = float
price = 3.14159
print("মূল্য: %.2f" % price)
# আউটপুট: মূল্য: 3.14
```

### Method 4: String Concatenation (জোড়া লাগানো)

```python
name = "রহিম"
age = 25

print("নাম: " + name + ", বয়স: " + str(age))
# আউটপুট: নাম: রহিম, বয়স: 25
```

⚠️ খেয়াল রাখুন: সংখ্যাকে string-এর সাথে জোড়া লাগাতে হলে `str()` দিয়ে রূপান্তর করতে হয়।

## ৩. Input — `input()` ফাংশন

ব্যবহারকারীর কাছ থেকে ইনপুট নিতে `input()` ব্যবহার করা হয়।

### মূল ব্যবহার:

```python
name = input("আপনার নাম লিখুন: ")
print(f"স্বাগতম, {name}!")

# আউটপুট:
# আপনার নাম লিখুন: রহিম
# স্বাগতম, রহিম!
```

`input()` সবসময় **string** আকারে মান ফেরত দেয়।

## ৪. Type Conversion সহ Input

যেহেতু `input()` সবসময় string দেয়, তাই সংখ্যা নিতে হলে `int()` বা `float()` দিয়ে রূপান্তর করতে হয়।

### Integer Input:

```python
age = int(input("আপনার বয়স দিন: "))
print(f"পরের বছর আপনি {age + 1} বছরের হবেন")

# আউটপুট:
# আপনার বয়স দিন: 25
# পরের বছর আপনি 26 বছরের হবেন
```

### Float Input:

```python
price = float(input("দাম দিন: "))
discount = price * 0.1
print(f"ডিসকাউন্ট: {discount} টাকা")

# আউটপুট:
# দাম দিন: 100
# ডিসকাউন্ট: 10.0 টাকা
```

### একাধিক ইনপুট এক লাইনে:

```python
# এক লাইনে দুই সংখ্যা ইনপুট
a, b = map(int, input("দুই সংখ্যা দিন (space দিয়ে): ").split())
print(f"যোগফল: {a + b}")

# আউটপুট:
# দুই সংখ্যা দিন (space দিয়ে): 10 20
# যোগফল: 30
```

`split()` — input string-কে space দিয়ে ভেঙে list বানায়।
`map(int, ...)` — list-এর প্রতিটা উপাদানকে integer করে।

## ৫. একাধিক ইনপুট List আকারে নেওয়া

```python
# একাধিক সংখ্যা ইনপুট দিয়ে list তৈরি
numbers = list(map(int, input("সংখ্যাগুলো দিন (space দিয়ে): ").split()))
print(f"সংখ্যা: {numbers}")
print(f"যোগফল: {sum(numbers)}")
print(f"সর্বোচ্চ: {max(numbers)}")

# আউটপুট:
# সংখ্যাগুলো দিন (space দিয়ে): 5 10 15 20
# সংখ্যা: [5, 10, 15, 20]
# যোগফল: 50
# সর্বোচ্চ: 20
```

### কোমা দিয়ে আলাদা ইনপুট:

```python
values = input("কোমা দিয়ে সংখ্যা দিন: ").split(",")
numbers = [int(v.strip()) for v in values]
print(numbers)

# আউটপুট:
# কোমা দিয়ে সংখ্যা দিন: 5, 10, 15, 20
# [5, 10, 15, 20]
```

## ৬. Error Handling সহ Input (বোনাস)

ভুল ইনপুট দিলে প্রোগ্রাম crash না করার জন্য try-except ব্যবহার করা যায়:

```python
try:
    age = int(input("আপনার বয়স দিন: "))
    print(f"আপনি {age} বছরের")
except ValueError:
    print("দুঃখিত, একটি সংখ্যা লিখুন!")

# আউটপুট:
# আপনার বয়স দিন: ২৫ (বাংলা সংখ্যা বা অক্ষর দিলে)
# দুঃখিত, একটি সংখ্যা লিখুন!
```

### লুপ দিয়ে সঠিক ইনপুট নেওয়া:

```python
while True:
    try:
        age = int(input("আপনার বয়স দিন: "))
        break
    except ValueError:
        print("অনুগ্রহ করে একটি সংখ্যা লিখুন।")

print(f"আপনি {age} বছরের")
```

## ৭. Practical Exercise

নিচের কোড রান করে দেখুন:

```python
# --- Exercise 1: সাধারণ প্রিন্ট ---
print("=== পরিচিতি ফর্ম ===")
name = input("আপনার নাম: ")
age = int(input("আপনার বয়স: "))
city = input("আপনার শহর: ")

print(f"\nহ্যালো, {name}!")
print(f"আপনি {age} বছরের এবং {city} তে থাকেন।")

# --- Exercise 2: ক্যালকুলেটর ---
print("\n=== ক্যালকুলেটর ===")
a = float(input("প্রথম সংখ্যা: "))
b = float(input("দ্বিতীয় সংখ্যা: "))

print(f"যোগ: {a + b}")
print(f"বিয়োগ: {a - b}")
print(f"গুণ: {a * b}")
print(f"ভাগ: {a / b}")

# --- Exercise 3: একাধিক ইনপুট ---
print("\n=== একাধিক সংখ্যা ===")
nums = list(map(int, input("সংখ্যাগুলো দিন (space দিয়ে): ").split()))
print(f"সংখ্যা: {nums}")
print(f"মোট: {len(nums)} টি")
print(f"যোগফল: {sum(nums)}")
print(f"গড়: {sum(nums)/len(nums)}")
print(f"সর্বোচ্চ: {max(nums)}")
print(f"সর্বনিম্ন: {min(nums)}")

# --- Exercise 4: f-string ফরম্যাটিং ---
print("\n=== ফরম্যাটিং ===")
price = 1500.5
print(f"মূল্য: {price:.2f} টাকা")
print(f"ডিসকাউন্ট: {price * 0.1:.2f} টাকা")
print(f"পরিশোধযোগ্য: {price * 0.9:.2f} টাকা")
```

## 🎯 আজকের Key Takeaways

1. **`print()`** — কনসোলে আউটপুট দেখায়
2. `sep` প্যারামিটার দিয়ে মানগুলোর মাঝের সেপারেটর পরিবর্তন করা যায়
3. `end` প্যারামিটার দিয়ে শেষের ক্যারেক্টার পরিবর্তন করা যায়
4. **f-string** (`f"..."`) — সবচেয়ে সহজ ও শক্তিশালী string formatting
5. **`input()`** — সবসময় string আকারে মান দেয়
6. সংখ্যা নিতে `int(input())` বা `float(input())` ব্যবহার করতে হয়
7. একাধিক ইনপুট: `map(int, input().split())`
8. `try-except` দিয়ে ভুল ইনপুট হ্যান্ডেল করা যায়
